# ADR-001: Use SQLite for initial local storage

Status: Accepted
Date: 2026-09-21

## Context

QFL starts as a single-user, local application storing market data.

## Decision

Use SQLite as the first database.

## Reason

- No server to install, run, or secure
- One file, easy to back up and reset while learning
- Enough capacity for the early data volume
- Teaches SQL fundamentals

## Consequences

- One writer at a time
- May need to migrate to a server database (for example PostgreSQL) if we need concurrent writers, heavy time-series queries, or multi-user access
- Keep database access behind a storage module so a migration stays contained
